# 世界小报｜编辑规范

面向约6–8岁儿童的晚间新闻音频；年龄范围是编辑起点，不是对所有儿童能力的统一判断。具体称呼、年龄、兴趣与收听场景从本机 `config/local.json` 读取；缺省使用 `config/local.example.json` 的通用设置。先用实际反馈修订内容，再决定自动化方式。

## 1. 节目的承诺

每次陪孩子认识世界的一小部分：一件真实的事，一个能理解的新认识，一个允许有自己答案的问题。

目标是孩子愿意听、能跟住、偶尔主动追问。不要把记住新闻人物、数字或术语当成每天的任务。每天更新不等于每天追最热、最重大、最刺激的新闻。

主持人像认真又有趣的大朋友。默认称呼“小朋友”，个性化称呼只从本机配置读取，不装婴儿语气，不高高在上，不用“这么简单你肯定知道”。允许孩子不知道、不回答、改主意。不要使用参考节目的主持人身份、口号或声线冒充原栏目。

### 固定开场

每期先用 `examples/episode-opening.txt` 的两行片头：一行有节奏的短句说明“听新闻、长知识、看世界、想问题”，再点明这是给本机配置中听众的新闻小报。原文以该模板为准，称呼经 `scripts/prepare_script.py` 渲染后只放本地稿件，不把个人称呼写入公开文件。

片头预计约8–12秒，以实际声线为准。用清楚、轻快、有辨识度的短句节奏，不做夸张叫喊；接着直接进入真实事件或具体问题。开头不再说“晚上好”“早上好”“大家好”或“欢迎来到”，也不在口号后再补一轮问候。它占用原开门预算的一部分，第一分钟交代事件的要求不变。新稿统一采用；用户要求修正已交付节目时，另存修正版并同步其正文、音频和当前归档入口，原音频对应旧正文及付费缓存留存，避免文字与声音错版。

### 固定结束语

开放问题与必要的收束之后，使用 `examples/episode-ending.txt`，节目身份后直接说“我们下次再见”。不再追加“晚安”“早点休息”“做个好梦”等睡眠或时段祝福，也不先说“今晚的故事就到这里”再重复告别。收听场景仍影响内容情绪和互动方式，结束语统一。节目名从本机配置渲染，不写入公开模板；修正当前交付时同步文字、音频与归档，并回读核对结尾。

## 2. 选题先过门槛，再比较趣味

先满足以下条件：

- 找得到支持核心事实的可靠原始资料，能确定发生日期。只有转发截图、营销文章或模型记忆时，不能直接写成新闻。
- 能用一个画面说清“谁在做什么、遇到了什么问题”。
- 不依赖先讲清多个国家、制度、经济学或历史背景才能听懂。
- 适合当天的晚间情绪。严重伤亡、暴力细节、失踪、威胁和仇恨动员不进入睡前版。
- 这件事能自然引出一个问题，不是勉强在结尾贴一段百科知识。
- 材料里至少有一个能支撑叙述的真实细节：人的行动、具体物件、实际使用过程或可核实的前后变化。只有机构宣布和宏观数字时，先补材料、缩短或换角度，不能用更长的想象故事补位。

通过后，按五项各 0–2 分粗筛：近期事件是否值得认识；能不能想象场景；一个问题能否讲完；事实是否清楚；结尾能否平静收束。8 分以上优先，6–7 分需要改角度；这是编辑辅助，不是科学量表。

选题跟随近期真实时事，覆盖国内与国际、社会生活、科学技术、商业、文化、运动等领域。检查最近两周的内容，主动补充缺少的领域、地区与生活处境，不用兴趣反馈持续缩窄选题。孩子的兴趣只帮助选择比喻与解释入口。商业与社会规则可以落到借东西、排队、买玩具、分享空间等具体情境。

### 可以寻找的八类新闻线索

下表保留为讲述切口的例子，不是固定选题池，也不是八条已经发生的今日新闻；日常先从综合时事获取候选。

| 方向 | 能吸引孩子的问题 | 留下的一个理解 | 可以聊的事 |
|---|---|---|---|
| 动物园给动物称重 | 小企鹅会乖乖站上秤吗？ | 观察和测量帮助照顾动物 | 怎么让动物愿意配合？ |
| 动物通道/生态桥 | 给小动物修的桥，人能走吗？ | 人的道路也影响动物的路 | 怎么给小动物留条路？ |
| 鸟类迁徙观测 | 小鸟去旅行，怎么知道它到哪了？ | 证据来自观察记录 | 你会记下哪些细节？ |
| 新的太空样品/探测成果 | 一小块石头为什么值得研究？ | 不同证据回答不同问题 | 想让探测器帮忙看什么？ |
| 机器人完成生活小任务 | 会跑的机器人，为什么拿不好鸡蛋？ | 不同任务需要不同本领 | “做得好”该看什么？ |
| 接力赛、混合团队项目 | 跑得最快的人，为什么不一定赢接力？ | 配合也需要练习 | 怎样把东西交给同伴？ |
| 儿童友好的新发明 | 一个小改变，能让谁更方便？ | 设计从别人的困难出发 | 家里哪个小麻烦能改一改？ |
| 植物、昆虫的新发现 | 小小一片叶子上有什么秘密？ | 先观察，再猜，再找证据 | 你看见的和猜的有什么不同？ |

不按性别限定兴趣。运动不只讲冠军与天赋，动物不只讲“萌”，科学不只讲“震惊世界”。

## 3. 先讲清事件，再决定长度

写稿前先用普通话写出“谁遇到什么困难→采取什么行动→这次出现什么变化”，再确定一个值得听下去、且正文确实能回答的问题。题材陌生不等于没有兴趣；先检查是否交代了值得关心的处境，不因一次走神就按兴趣缩窄领域。

固定片头后先给真实对象和具体困难，尽快落到本次新闻。第一分钟应能听明白何时、何地、谁在做什么，以及与之前相比发生了什么。发布时间可简述，发布会流程不必成为叙事中心。问题应推动追问，不用听众已能立刻回答的“照片能不能传到远方”一类常识问句撑全篇；也不靠夸张或虚构制造悬念。

默认成品约15分钟，通常14–16分钟。参考节目有两层结构：整集常为开场、头条、其他新闻、上期反馈；头条内部则是一条不断生出下一问的问题链。这里保留每期一个主事件，重点借鉴头条的推进、换位和角色选择，不把整集15分钟误当成必须用一个比喻讲15分钟，也不为仿栏目而编造留言或新增多条新闻。详细样本边界见 `docs/参考节目分析.md`。

下表是单主事件版的内容预算，可随事件调整；每一段应带来新的事实、关系、条件或判断，而不只是换词重复：

| 位置 | 内容任务 | 时间预算（供试读） |
|---|---|---:|
| 开门 | 具体矛盾，前一分钟交代事件、新变化，并预告要追的两三个相连问题 | 0:00–1:00 |
| 讲事 | 经过、真实的人或具体使用过程；交代之前与现在，必要背景随疑问补入 | 1:00–4:00 |
| 追问与解释 | 一个问题引出下一个；旧办法为什么卡住，新办法怎样回应，解释后回到事实 | 4:00–8:00 |
| 换位看 | 从相关人的不同需要看条件和代价；说明一种办法何时适合、何时不足 | 8:00–11:00 |
| 角色选择 | 让孩子在同一事件里作一个小选择，思考后展示不同合理理由 | 11:00–13:30 |
| 回来与收尾 | 回答开头，用核心理解连回日常；一个开放问题，平静告别 | 13:30–15:00 |

这不是必须卡秒的格式。时长目标依据用户最新反馈由短版改为约15分钟；用真实过程、因果层次、不同处境和角色选择增加内容。原短版继续保留，不能因改原则而改写对应音频的旧稿。初稿字数参考既有声线实际字速，写完先估时，最终以TTS实测校准，不靠拉慢、加长静默或百科支线凑时长。若材料撑不起层次，应补资料或换角度；不得捏造新闻细节。

讲事时让真实材料推动叙述：先让听众知道具体发生了什么、为什么需要这个办法，再解释它怎样起作用。可以展开同一事件中几个各有作用的案例，但不能把同一经过复述三遍。类比短而必要，解释后回到新闻中的人、行动或变化。角色选择是练习看见不同需要，不冒充实际订单、现场或受访者观点。真实反馈只有确实收到才能回应，没有则省去反馈栏目。

每集最多一个需要真正掌握的概念。出现第二个概念时问：删掉它，主问题还能讲明白吗？能，就删或留到下一期。事实需要的名词可以出现，但不自动变成教学目标。

## 4. 把“写给眼睛”改成“讲给耳朵”

- 一句话完成一个主要动作或判断。长因果链拆开，用“可是”“所以”“现在回头看”提示关系。
- 先出现具体东西，再说名称。不要先报术语，再用更多术语解释。
- 同一比喻尽量贯穿；不要在两分钟内从书桌跳到公路再跳到工厂。
- 类比的边界要自然说清。例如“我们把它想成传话的伙伴，真正传递的是信号”。
- 少数必要数字保留，其他变成可想象的尺度；不能为了好懂改错数量级。
- 复述是在新位置把问题接回来，不是把同一句话重复三遍。
- 转场应解释“为什么接下来要讲这个”，不能只有一段音乐硬切。
- 不编人物原话、心情、现场反应和戏剧细节。需要假设时直接说“假设”“想象”。
- 边界说明紧贴对应内容说清即可，不反复打断故事；不能为了流畅删除必要的事实限定。
- 不用提问密度冒充互动。一集安排 2–3 次真正能停下回答的机会，其他问句可由主持人自问自答。不要孩子还没想好就立刻揭晓。
- 不用“你真聪明，答对了”预设孩子的答案。可以说“你也可以有别的想法”“我们再找一条线索”。

## 5. 晚饭后与睡前

晚饭后：可以观察桌上一件东西、试一个安全的小动作，或者和家长轮流说理由。互动可稍活泼。

睡前：不要求起床找道具，不让孩子执行计时挑战；把动作改为想象。少惊叹、少悬而未决的威胁、少输赢压力。最后回答主要问题，不留下“明天揭晓可怕真相”的悬念。

一期内容可以只改互动和收尾，不需要机械生成两篇几乎重复的新闻稿。

## 6. 声音与音乐的制作意图

以下是本节目的制作建议，不是对参考音频原曲、乐器或混音参数的鉴定。

声音应清楚、亲近、有一点表情。新名词前后放慢，主要问题后停一下。可以说“小朋友，你想一想”，不要整段都兴奋上扬。

片头用一段简短、可识别的温柔旋律；转场只在大段落边界出现；片尾慢慢结束。优先无歌词、少音符、不抢节奏的音乐。讲新知识、需要分辨事实、等待回答时，可以完全没有音乐。

如果保留连续底乐，要确保小音量播放时每个字仍清楚；不要用大起伏、突然鼓点或警报模拟“新闻感”。用户已取消人工审核，保留自动技术检查，完成后直接放行；耳机和手机实际收听反馈用于后续改进，不是交付前置条件。音乐素材来源和使用授权应独立保存，不从参考节目里提取配乐来复用。

TTS 与混音已接入；实际能力和操作入口见 README 与 `docs/音频制作.md`。个性化历史样稿及音频仅保存在被忽略的本地目录。

## 7. 每期只需一页家长底稿

记录标题、发生日期、资料发布时间/核查时间、来源链接、3–5 条事实、一个核心问题、一个记忆点、类比、互动、未知或有争议之处。

事实用“发生了/观测到/机构公布”；预测用“预计/可能”；尚无答案用“目前还不知道”；观点说清“有人认为/我的理解是”。一篇文章不因为被多个网站转载就变成多源验证。

在没有合适新事件的日子，可以明确播一条近期或历史新闻，或回访孩子先前的问题。不能为了每日更新编造事件，也不能让 2024 年的事听起来像今天发生。

## 8. 可复用的写稿任务说明

> 请根据下方已核验的新闻事实，为“世界小报”写约15分钟中文口播稿，通常14–16分钟，以最终音频实测为准。默认面向约6–8岁儿童，晚饭后或睡前听；如有本机配置，按其调整解释方式，个人信息不写入公开文档。先给出“谁遇到什么困难→做了什么→这次有什么变化”、一个核心问题、一个核心理解，再列递进问题链及各段新增内容。前一分钟交代真实事件。沿“具体矛盾→真实过程→递进追问→机制解释→不同人的条件与代价→角色选择→回扣”推进，用真实行动和前后变化支撑故事。类比只辅助，角色选择明确为假设，不取代新闻。少量互动留出停顿，结尾兑现主问题，留一个开放问题；有真实反馈才回应，不编听众留言。不得靠重复、知识堆叠、慢速或静默凑时长。不得补造事实、现场或引语；不足则补证据或换角度。区分事实、猜测、预测和类比，必要限定就近说清。正文与制作提示分开，事实列出处，历史背景标时间。自审事件是否清楚、问题链是否前进、每段是否增加新内容、类比是否抢主线。

这份提示词不能代替选题、事实核查与编辑自检；不要求家长审核后才交付。

## 9. 第一轮怎么判断是否好听

先从近期时事中选三个不同领域的题材试播。观察孩子在哪里主动插话、哪里要求解释、哪里走神、是否想再听；不要求孩子每天复述或做题。家长记下一个有效片段和一个卡住的地方即可。

如果孩子只记住可爱的细节，也不急着算失败；先判断事件是否清楚、细节是否连着主问题。如果觉得没意思，先检查是否建立了值得关心的困难、解释前是否已讲明事件；再判断领域偏好。用户已反馈短版不错但偏短，后续按约15分钟制作，重点观察各段是否仍有前进感。通常每次只调一个变量，便于判断变化来自哪里；用户明确要求同时换题和改结构时照做，并记录不能据此断言某个改动单独有效。

交付前在 `brief.md` 写一段叙事自审：第一分钟的事件要素在哪里；哪个真实细节支撑主故事；开头的好奇点在哪里兑现；类比结束后怎样回到事件；删掉了哪些重复或支线。再做一次简短的无稿回想：能否用两三句讲清这件新闻，而不只复述原理？如不能，回到讲事段修改。
