# 制作与验证概况

以下为2026-11-05本地试跑的历史结果，不代表新检出仓库已包含音频素材或已配置归档目标。个人配置、正文、试听、成品、任务缓存和上传记录均留在 Git 忽略的本机文件中。当前使用入口以 README 与 [音频制作](音频制作.md) 为准。

## 配音与混音

- 已验证火山 TTS 的提交、查询、下载、24kHz单声道MP3和字级时间戳；支持新版 API Key 及旧版 App ID + Access Token，兼容历史变量拼写。
- Vivi、小何、云舟、小天四种声线已生成本地试听；日常池为Vivi和云舟，等概率按节目日期选择并持久化，同日重跑复用，允许连续多日相同。
- 已验证简单侧链压低底乐与整期按文字锚点加入停顿、短配乐的编排。高码率母版与较小交付版分别保留；两个归档渠道使用同一交付文件。
- 已验证成功缓存复用、参数不同拒绝覆盖、TTS查询既有任务、音乐结果不确定时不自动重发及锁释放。技术检查包含完整解码、格式、时长和响度。
- 检查通过后自动设为“已通过”，不等待人工听审，不声称完成了人工试听或儿童适配验收。

## 音乐库存

本机共27段，约22.9分钟。最初5段、首轮新增20段、后续新增2段；后续计划因额度不足停止，未完成清单不计入库存，不自动恢复。前25段保留已有用户认可状态，新曲仍待听审，无缝循环接点未验收。

`config/music-library.json` 保持 `reuse-only`，片头固定 `01-opening`。没有合适库存时留白或报告缺口；只有用户日后明确授权扩充才可解锁生成。公开仓库保留目录与计划，本机素材和供应商侧车另行备份。详情见 [音乐库](../assets/music/library.md) 与 [音乐生成记录](音乐生成记录.md)。

## 交付与自动化

历史试跑已完成一期音频和由代理通过连接工具触发的单次 Notion 上传归档。私人目标与访问地址保存在 `config/local.json`，每期上传结果在 `episodes/` 中查重。网盘上传尚未完成，两条独立无人值守上传链路均未实现；没有创建定时任务或额外消息推送。

新闻源清单仍待评审，尚未启用正式每日采集。参考节目研究及历史样稿不能作为当日新闻。具体范围见 README「每日创作入口」与「交付与归档」。
