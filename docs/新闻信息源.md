分工是编辑选择，不是“权威排名”。国内两家也可能共享稿源，国际两家也可能都引用同一通稿；每次仍要检查独立性。四个入口不要求每期全部引用，目的是让候选池有足够宽度。

## 日常使用方式

先看最近14天节目，找缺少的领域、地区和生活处境；再浏览国内与国际综合入口，优先近72小时、必要时近7天。列3–5个候选，记录实际发生日期、报道日期、儿童切口与不选的理由。通过编辑规范后，才追原始证据、确定一个核心理解并写口播。

关注社会、商业和文化，不等于要求孩子理解复杂制度。找能落到生活的问题，例如公共空间如何分享、一件物品怎样被保存、比赛为何需要约定。动物和科学也可以讲，但不能把兴趣变成固定选题池。

来源评审时检查：范围是否够宽、正文能否读到、日期是否清楚、能否追到原始事实、两个来源是否实际独立。确认名单后再更新对应 `review_status` 与 `enabled`；来源启用只表示编辑可使用，不自动创建定时任务。

原始技术结果保存在 [本轮访问记录](news-source-check-2026-11-05.json)。记录只保存访问状态、标题、日期等元数据，不归档整站正文。RSS与抽样HTTP请求在本机只读执行；栏目和部分正文另由检索工具阅读。未完成无人值守采集、长期稳定性和家中网络验证。
