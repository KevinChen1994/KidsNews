# 音乐生成记录与维护说明

这是一次性素材准备的操作记录，不是日常 skill。2026-11-05 起音乐库保持 `reuse-only`；以下生成命令仅供用户日后明确授权扩充时参考。日常选曲见 [音频制作](音频制作.md)。

在项目根目录工作，先看 `assets/music/catalog.json` 和现有 `.mp3`/同名 `.json`。用户要求本轮一次性扩充后长期复用。日常只选库存，不因为整期缺配乐而自动生成新曲：可以留白或报告缺口。读取 `config/music-library.json`；`generation_mode: reuse-only` 时脚本会拒绝新生成。只有用户日后明确要求扩充，才可修改策略重新调用 API。

`python3 scripts/audio.py music --help`。脚本只从本机 `.env` 或环境读取 `ELEVENLABS_API_KEY`。使用官方音乐接口 `POST https://api.elevenlabs.io/v1/music`；这是音乐，不要用音效接口冒充。默认 `music_v2_5`，可显式指定其他受支持版本。

把用途、乐器、节奏、情绪、段落和结束方式写清楚。儿童晚间节目适合克制、亲近、有好奇感的原创纯器乐：少音符、少鼓点、无突然冲击、不过分兴奋。背景音乐避开抢人声的主旋律；片头可以有短动机。脚本强制 `force_instrumental=true`，仍需实际听审。

```bash
python3 scripts/audio.py music --prompt 'Gentle original instrumental curiosity bed, sparse felt piano and marimba, 78 BPM, warm, restrained, no vocals, no dramatic changes, gentle ending.' --seconds 30 --output assets/music/curiosity-02.mp3
```

历史扩充计划为新增20段90秒底乐、3段8秒转场、2段20秒片尾，见 `assets/music/library-expansion-2026-11-05.json`；原计划完成后共50段，实际在新增2段后因额度不足停止，当前27段。未完成项目不能算成品，也不因额度补足而自动恢复；用户日后明确要求扩充后再处理。`authorized-batch` 策略仅放行清单中的精确请求；维护结束后设回 `reuse-only`。片头固定 `01-opening`。时长范围3–600秒；`--dry-run` 仅显示请求。MP3以44.1kHz/128kbps保存，同名 `.json` 保存完整提示词、模型、song_id（服务返回时）、状态、文件摘要。

调用前检查缓存。同名成功结果自动复用，参数不同时拒绝覆盖。音乐生成遇到超时或断线时，服务端可能已收费；状态文件会阻止自动重新提交。权限、套餐或余额错误停止该批次并报告，不通过换模型或换接口规避。只有确认要新生成时才用新的输出文件名。

用 ffprobe 检查可解码、时长、声道；听审后更新 `assets/music/catalog.json` 的 review 状态及用途。生成成功不等于质量通过，未试听必须标记 pending。保留提示词/来源/生成日期，不把曲目描述成已经法律审核或天然获得无限商用权；发布需要时查账户对应条款。

库存用途、情绪和搭配方法见 `assets/music/library.md`，未听审的循环衔接不能标作无缝循环。

当前接口细节见 [ElevenLabs 官方文档](https://elevenlabs.io/docs/api-reference/music/compose)。

经用户要求，`assets/music/` 中27段库存MP3已纳入Git版本管理，目录与生成计划一并保留；来源和授权限制见[配乐授权说明](../assets/music/NOTICE.md)。本地提交不代表已获公开素材库分发授权。供应商同名元数据和批次 `.results.json` 继续由 `.gitignore` 排除，迁移制作环境时需另行安全保留这些缓存，避免重复计费。缺文件时仍不自动重新生成。
